# Coding skills

ここが共有 Agent Skills の原本です。各 `<skill-name>/SKILL.md` を編集します。
リポジトリの `.agents/skills`、`.claude/skills`、`.codex/skills` はこの場所への alias なので、
コンテナを使わない場合も同じ内容を利用できます。

- [readable-code](readable-code/SKILL.md): 読みやすいコードを書く規約。
- [verify-deliverables](verify-deliverables/SKILL.md): 成果物と検証結果の確認。

[利用・追加方法](../../../docs/claude-codex/coding-skills.md) を参照してください。
テンプレートは discovery を避けるため [docs 配下](../../../docs/claude-codex/skill-template/SKILL.md) にあります。
