## 全体を分類した結果

| 資料の領域 | 本リポジトリでの扱い |
| --- | --- |
| モデルの自己説明・日付・知識範囲・ユーザー状態 | 移植しない。実行環境の情報を使う |
| 会話、分野別の注意、拒否や書式の指定 | 移植しない。コーディング成果物の検証とは別の責務 |
| 検索・出典・ツール選択 | 情報の版と実際に利用できる手段の確認へ整理 |
| ファイル作成・成果物の引き渡し | 保存した実物と、利用者からの参照可能性を確認する手順へ整理 |
| skills、ファイルパス、依存ライブラリ、パッケージ操作 | 固定値や一律の操作は移植せず、対象環境の確認へ置き換える |
| ブラウザ内成果物、永続化、API 接続 | 専用の実行環境に依存するため API・設定・サンプルは移植しない |
| ツールの全定義、コネクタ、共有操作 | 同梱しない。現在提供されている定義と既存の許可を使う |
| ネットワーク、読み取り専用領域、出力場所 | 掲載環境の設定を引き継がず、実際の環境で確認する |

必ず使う規則は採用していない。資料の内容を後から取り込む自動更新処理もない。
